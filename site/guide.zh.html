如何用 Codex 或 Claude Code 生成易读的 HTML 技术报告

从安装 Agent Skill 到组织结论、证据与验收边界。

1. 安装并确认加载

在项目目录执行下方命令，按提示选择宿主，确认 gen-ui 已加载。

npx skills add yeqiana/gen-ui --skill gen-ui

2. 从一个问题开始

使用 gen-ui 分析以下虚构场景，不访问真实代码库：同步任务超时后可能重复执行。A：延长超时；B：持久化状态、幂等键和有界重试。先给条件性结论，比较风险及缺失证据。输出 Markdown，不虚构测试。

3. 对照参考结构

说明示例，非实测模型输出

结论：若任务可能重复执行，优先研究 B；延长超时不能证明解决重复执行。

依据：A 改变超时边界，B 明确状态及重复执行控制。

风险：幂等范围、状态转换与恢复策略仍待设计，没有真实测试证据。

下一步：确认副作用，测试超时、重试与崩溃恢复。

4. 按需请求 HTML

要求生成使用本地资源的离线 HTML，保留相同事实和验收边界。可参考现有架构设计和测试验收示例，它们并非上述提示词的实际输出。

5. 检查交付

检查结论、事实、证据、离线可读性和窄屏溢出。美观不能证明正确。

How to generate readable HTML technical reports with Codex or Claude Code

Install an Agent Skill, structure a decision and check evidence in a readable offline HTML report.

1. Install and confirm discovery

Run this in your project, select your agent and confirm it discovers gen-ui.

npx skills add yeqiana/gen-ui --skill gen-ui

2. Start with a problem

Use gen-ui to analyze this fictional scenario without inspecting a real repository: A synchronous job may run twice after a timeout. A: extend the timeout. B: persist state, use idempotency keys and bound retries. Start with a conditional conclusion; compare risks and missing evidence. Output Markdown; do not invent tests.

3. Compare an example structure

Illustrative structure, not measured model output

Conclusion: If jobs can run twice, investigate B first. Extending the timeout does not establish duplicate prevention.

Evidence: A changes a timeout boundary; B makes state and duplicate controls explicit.

Risk: Idempotency scope, state transitions and recovery still need design. No real tests are available.

Next: Identify side effects; test timeouts, retries and crash recovery.

4. Request HTML when useful

Request offline HTML with local assets and the same facts and evidence boundaries. See the existing architecture and acceptance examples. They are not actual outputs of the prompt above.

5. Verify delivery

Check conclusions, facts, evidence, offline readability and narrow-screen overflow. Formatting does not establish correctness.

常见问题

GEN-UI 是什么？
免费的开源信息设计 Agent Skill，帮助 AI 给出更清晰的解释、结构化 Markdown，并按需生成易读 HTML。
GEN-UI 是 Generative UI 前端框架吗？
不是。它指导 AI 组织和呈现信息，不替代 React，也不是应用开发框架。
能在 Codex 和 Claude Code 中使用吗？
仓库提供两种宿主的安装说明，实际 Skill 发现与工具权限取决于宿主。
需要额外 API Key 或云服务吗？
Skill 本身不需要额外云服务，使用已有 AI Agent；示例 HTML 可离线打开。
可以生成技术报告和架构图吗？
可以，在用户要求且宿主支持 HTML 时使用本地渲染资源。不会虚构实现、测试或部署证据。

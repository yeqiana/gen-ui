# GEN-UI 稳定基线 · 2026-11-16

**状态：受控交付稳定基线。** 明确要求使用 GEN-UI 的三个不同主题，在本地 Runner 一次性预置标准 CSS/JS 后，原生模型分别独立生成 HTML 和 SVG，并通过 **3/3 静态、179/179 Chrome 交互/内容、18/18 Typography**。另一次未点名 Skill 的会话成功自动触发 Skill，但没有完整交付验证。

与 2026-11-14 基线相比，这轮重点不是新 UI 组件，而是 **资源交付可重复、模型先完成 HTML、纠正摘要加粗带来的提前换行，以及按真实段落检查**。主 Skill 仍保持约 5 KiB，不增加依赖。

这不是对任意宿主或自主打包资源成功率的承诺。已生成的报告和 SVG 原始字节不变，最后只同步更新了公共 CSS。详见 [第三阶段完整验收记录](../evals/independent-html-stability-2026-11-16.md)。

后续原则：有失败证据再局部修复；不再用新增一批覆盖选择器解决同类问题；不把页面门禁当成业务系统的功能测试。

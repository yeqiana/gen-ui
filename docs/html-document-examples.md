# 技术文档 HTML 示例：来源、边界与验收口径

> 更新：2026-11-09。本文解释公开示例的内容来源与真实性边界。

## 为什么选择这四种文档

GEN-UI 面向 Coding Agent 的核心任务包括理解项目、制定架构、拆解实施和验证交付。HTML 输出的价值应体现在长文档的信息组织与工程表达，而不是将业务应用重新画成一套控制台。

| 示例 | 展示能力 | 内容范围 |
| --- | --- | --- |
| 项目分析报告 | 复杂信息梳理 | 项目目标、系统边界、模块职责、数据流、风险与建议 |
| 架构设计方案 | 工程设计论证 | 组件图、状态机、时序图、数据模型、一致性与恢复策略 |
| 技术实施方案 | 可执行计划 | 范围、阶段、依赖、迁移、灰度、回滚和验收门禁 |
| 测试验收方案 | 验证设计 | 测试矩阵、用例、故障注入、性能测试与证据要求 |

## 内容与脱敏边界

- 四份文档使用统一的虚构/重制 AI 内容生产平台作为案例，使分析、设计、实施和测试之间的术语与数据模型保持一致。
- 不包含私有仓库代码、真实用户数据、模型密钥、内网地址、生产日志或未授权截图。
- 文档中的任务 ID、表结构、流程图和参数均为演示材料；不应当作真实项目的已验证设计。
- 测试用例全部是待执行方案；性能并发数仅为测试阶梯示例，不是实测吞吐或 SLA。
- 图表由 HTML 内联 SVG 绘制；CSS、JS 与预览图片均为本地文件，不调用外部字体、图片或 API。

## 视觉与交互约束

- 正文是文档主体：标题层级、段落、长表格、列表、代码和附录优先。
- 左侧目录对应正文真实章节锚点；移动端目录可折叠。
- 架构图、状态机和时序图有文字说明，并支持缩放、拖动、适应窗口和全屏。
- 代码块保留空白与横向滚动，复制操作仅复制代码本身。
- 桌面、平板、手机均可阅读；打印时隐藏导航和图表操作控件。
- 页面默认白底、正文 14px、代码 12px、强调色 #3A83F7；不加载远程字体。

## 本地复验

~~~powershell
node tests/documents.test.mjs
node tests/chrome-documents-smoke.mjs
~~~

浏览器测试覆盖四份文章和文档目录在 1440、768、375 三种视口下的结构、横向溢出、目录锚点、图表控件和离线资源引用。该测试只验证仓库固定示例，不代表任意模型输出都自动满足规范。

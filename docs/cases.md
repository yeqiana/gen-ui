## 脱敏方式

- **不用原始业务截图：** StoryOS 的原始浏览器截图确实存在，但含作品名称、人物画面和工作区信息；公开版完全重绘并换用虚构名称、抽象封面与数值。
- **不用原始企业代码或业务明细：** IM、冷热库只提炼可公开的架构概念，不复制原项目包名、域名、内网地址、数据库账号、接口密钥、真实群聊与私有日志。
- **设备信息不出仓：** Android TV 仅保留 Android 版本级兼容约束，不包含具体电视 IP、MAC、序列号、家庭网络。
- **演示统计不得冒充成果：** QR Audit 与页面内的数量、比例、消息编号为合成数据。真实审计结果必须保留输入 SHA、策略版本、执行记录和测试上下文。
- **图片生成方式：** 预览 PNG 由仓库内对应 HTML 在本地 Headless Chrome 中渲染，不能当作实机/生产截图。

## 已核实但不展示的范围

- StoryOS 真实 UI 的设计材料：`docs/StoryOS_WebConsole_R30_Creator_Home_20261011.md`、`R32_FourSlots_Functional`、`R33_Runtime_Readiness` 等（在私有/独立工作区，未复制进此仓库）。
- 企业 IM 当前源码仓库不在授权的 Runner 可访问路径内；报告仅基于历史材料。当前代码状态与线上运行状态 **未核实**。
- ELK、邀请注册、精灵守护未发现足够可靠的当前设计与截图证据，因此不作为“已完成项目案例”对外宣传。未来可在获得有权公开的材料后增补。

## 本地复验

页面均为离线 HTML，不加载外部图像、字体、脚本或 API：

~~~powershell
node tests/chrome-cases-smoke.mjs
~~~

该脚本只验证五个仓库固定页面的标题、截图和基本渲染，不对真实业务系统发请求。

# GEN-UI · 轻量化 Skill 设计原则

定位：轻量信息设计 Skill。先解决长文本难读、重点不明确、证据和结论混杂；不默认实现复杂网页。

## 八条原则

1. **轻入口，完整能力**：SKILL.md 只负责路由、输出决策和验收入口；精简只删冗余，不删事实、证据、约束或必要步骤；功能、安全与可访问性不得退化。
2. **按需加载**：Markdown 默认；HTML、架构图、七类语义图、多页门户、专用宿主协议各自只在需要时读取合约并加载资产。
3. **渐进增强**：可读文本 → 有组织的静态信息 → 表格/筛选 → 图表/全屏等交互。增强失败不能吞掉主要内容。
4. **语义优先**：分层、堆叠、归属不强制连线；只有存在明确依赖、顺序、流向、调用才考虑关系图。
5. **单一表达**：一篇文章只选一种标题编号；一个状态只使用文本、标签或图标中的一种；同源数据更新指标和表格。
   - 正文语义图标只标记特别准确且有依据的洞察（🎯）、有价值的新思路（💡）、证据明确的错误（❌）或具体风险/未验证点（⚠️）；普通叙述不装饰。
6. **默认可用**：HTML 报告默认左侧目录，支持最多三级、折叠与定位；常用操作 icon 化并保留 aria-label、title。
7. **防退化验证**：保留静态内容、移动端、离线、可访问性与主要交互；测试新规则和历史回归，不以截图取代浏览器操作验收。
8. **尊重证据边界**：示例、建议、已执行结果严格区分；不执行不可信模型脚本，不在无授权时操作外部系统。

以下为速览；完整的触发条件、格式优先级与降级边界统一见 [能力路由与加载边界](capability-routing.md)，不在此复制高级实现规则。

## 验收底线

- 默认目录在左侧，最多三级可折叠，导航与标题一致；移动端可访问。
- 标题编号不混排；时间可读且显示时不拖带 +08:00；状态单值；关键对比数据有颜色和文字标签。
- 全屏、图标工具栏、图片双击、滚轮、代码复制、分页、筛选真实生效，操作幂等。
- 在 375 / 768 / 1440 像素下核对布局；模型输入不能执行 HTML/JS。

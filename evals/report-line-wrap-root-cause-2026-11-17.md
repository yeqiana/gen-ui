# GEN-UI · report.html 句子提前换行根因与全景图配色复核

日期：2026-11-17。状态：本机实际 Chrome 验证通过，合并前仍以 CI 为准。

## 问题定位（不是 Markdown 转义）

针对用户给出的三处原句：

1. `#case-process > p`：上方的**内嵌 SVG 工程流程图**演示了可缩放、平移、全屏……
2. `#case-review > p`：**证据推演：**假设锁租约为 30 秒而任务耗时 45 秒……
3. `#case-guide > p`：这四份相互关联的**中文完整技术文档**对应不同阅读目的……

在 `demo/report.html` 源码中，上述三句都是正常的 `<p>` + 内联 `<strong>`；原文件无人工 `<br>`、无 `&#x20;` / `&#x5047;` 实体、无反斜杠星号。导致提前断行的 CSS 根因在 `demo/ui-refresh.css` 的原规则：

```css
#main :is(...,.case-block>p,.case-block>ul,.case-block>ol,...) {
  max-width: min(100%, var(--genui-prose-width));
}
```

`--genui-prose-width:72ch` 把**整页报告的案例正文**误限制在相对狭窄的阅读列里；父章节和相邻表格仍有空余，因而出现用户观察到的提前断行。此次移除案例正文、列表的错误限宽，设为所属章节实际 `100%`，保留 `text-wrap:wrap`。标题仍采用自身完整章节宽度的 `text-wrap:balance`，与正文使用不同策略。

## 精确段落 DOM 实测结果

同一份报告，Chrome 实际检查三个原句，均无 `<br>` 和错误转义；文本段落和相应 H3 标题占用以下宽度：

| 视口 / 导航 | 三段正文的宽度 | 对应章节宽度 | 标题宽度 | 结果 |
| --- | ---: | ---: | ---: | --- |
| 375px 展开 | 347px | 347px | 347px | 通过 |
| 768px 展开 | 725px | 725px | 725px | 通过 |
| 1440px 展开 | 1102.22px | 1102.22px | 1102.22px | 通过 |
| 1440px 折叠 | 1079.22px | 1079.22px | 1079.22px | 通过 |

验收入口：`node tests/chrome-report-smoke.mjs`。新增专门的三段文字 DOM + 宽度断言，防止未来仅凭无水平溢出而漏掉提前断行。原有标题孤字 Chrome 回归继续执行，不通过缩窄标题掩盖换行问题。

## 产品架构全景图样式

共享的 `assets/product-panorama-svg-theme.css` 已改为与现有 SVG 系列一致的点阵白底与五种可区分浅色层带：蓝、薄荷绿、淡紫、暖琥珀、浅青。标签、层容器和模块背景使用同一色系的不同明度；文本与边框保留足够对比。

**每个入口、层标签、模块卡片都取消左侧加粗/强调边线，四边使用相同细边框。** 同步适用于六层产品全景、四份中文技术案例，以及三份新增的离线项目演示。Chrome 验收检查不同层颜色数量、左右边框宽度一致、移动端仅图内滚动。

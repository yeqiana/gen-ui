## 最小修订与追加诊断

只在 evals/unseen-panorama-workflow.mjs 的通用配对提示中增加两条约束：证据逐字复制对应冻结文件中的连续片段，不得改写或拼接；全部必需边界必须出现在模块或关系的 evidence.quote 中，单写 notes 无效。baseline 与显式组获得相同的内容规则，未改核心 SKILL.md 或既定来源评分器。

新增一个负向单元测试：即使引用片段本身真实，遗漏必须保留的边界也必须 BLOCKED。

PlanShip 显式追加两个独立模型调用（非正式六组 A/B 的组成部分）：

1. **仅收紧引文提示**：Tool=Skill(gen-ui) 已真实加载，但响应被 Markdown 的 JSON 代码围栏包裹，违反严格 JSON 合约，**正式阻断**。仅作为诊断去掉围栏后，内部候选得到来源结构检查零问题；这个诊断结果不计入正式通过率。
2. **同一修订提示加 Claude 原生 JSON Schema 输出约束**：已真实加载 Skill，输出严格 JSON，但有 3 条引文错误，仍被来源校验阻断，未渲染 HTML。

这说明格式约束可单独成立，但不能代替来源可信性；一次诊断性好结果不保证下一次稳定。

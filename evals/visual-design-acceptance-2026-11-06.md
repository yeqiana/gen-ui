# GEN-UI 视觉规范补充验收（2026-11-06）

## 目标

将页面视觉从“组件堆叠”收敛为简约、聚合、图文清晰的阅读体验。规则以 `SKILL.md` 和 `references/html-report-contract.md` 为准。

## 强制检查

- [ ] 左侧导航收起后仍保留 56–72px 纵向图标栏；主导航每项均有图标，文字和二级导航隐藏。
- [ ] 展开/收起按钮位于侧边栏内部；展开和收起两种状态下都可见、可操作，并有中文无障碍名称与提示。
- [ ] 页面 H1 下方没有小标题；背景信息移至标题上方或首个内容区。
- [ ] 指标、图表、说明和操作按语义聚合，避免重复小节与碎片化卡片。
- [ ] 重要概念优先采用有意义的图示 + 简短中文说明；图片有 alt 和文字结论。无图像支持时有文字回退。
- [ ] Emoji 通常控制在每页 1–4 个，不代替状态和操作文字。
- [ ] 常用、明确的动作可图标化；重要或危险操作保留文字。
- [ ] 整体使用中性背景、清晰层级、适度留白和轻分割线，不堆叠卡片、重边框、渐变或阴影。

## 自动化验收

- `tests/report.test.mjs`：验证 H1 层级、图文示例、Emoji 数量和侧栏切换状态。
- `tests/portal.test.mjs`：验证生成入口的折叠结构与图标栏样式。
- `tests/chrome-report-smoke.mjs`：在 375/768/1440px 验证真实浏览器中的图标栏、切换按钮和图文结构。
- `tests/chrome-portal-smoke.mjs`：验证 iframe 门户折叠后仍显示纵向图标栏。

# GEN-UI 视觉规范补充验收（2026-11-06）

## 目标

将页面视觉从“组件堆叠”收敛为简约、聚合、图文清晰的阅读体验。规则以 `SKILL.md` 和 `references/html-report-contract.md` 为准。

## 强制检查

- [ ] 主题采用 #FFFFFF 背景、#1A1C1F 前景、#3A83F7 强调色；系统字体、正文 14px、代码 12px。
- [ ] 无原文 Markdown 下载、打印与源文本目录，也无多余浏览器标签操作。
- [ ] 多行代码采用 Markdown 风格代码块，每块均有离线可用的一键复制与成功/失败提示。
- [ ] 重要结论、关键数字、风险影响和行动要求选择性加粗，不整段加粗。
- [ ] 待确认、注意事项和风险引用块使用浅底色与语义色条；标题颜色保持统一，不因状态改变。
- [ ] 中文标题编号统一采用“一、二、三”或“1. / 1.1 / 1.2”中的一种，不混用。
- [ ] 实施任务状态使用统一图标：✅ / ❌ / ⏸️ / ⏳ / 🔄 / ❓ / ⚠️；不重复显示状态词，并具备无障碍名称与悬停提示。

- [ ] 左侧导航收起后仍保留 56–72px 纵向图标栏；主导航每项均有图标，文字和二级导航隐藏。
- [ ] 展开/收起按钮位于侧边栏内部；展开和收起两种状态下都可见、可操作，并有中文无障碍名称与提示。
- [ ] 页面 H1 下方没有小标题；背景信息移至标题上方或首个内容区。
- [ ] 总览使用少量醒目的指标卡片，图表、说明和操作按语义聚合，不堆叠无意义卡片。
- [ ] 重要概念优先采用有意义的图示 + 简短中文说明；图片有 alt 和文字结论。无图像支持时有文字回退。
- [ ] 主要栏目和按钮优先使用统一 SVG 图标，不用 Emoji 替代状态和操作文字。
- [ ] 常用、明确的动作可图标化；重要或危险操作保留文字。
- [ ] 中性背景、清晰层级、轻边框、紧凑按钮与少量明亮强调色搭配，避免堆叠卡片和重阴影。
- [ ] 成功与失败分别使用清晰的绿色、红色，表格状态可用浅底语义标签。
- [ ] 表格默认每页 10 条，支持页码、上一页、下一页、跳转以及 10/20/50 切换。
- [ ] 饼图、柱图、折线图使用语义清楚的多色组合，配有可读说明。
- [ ] 流程图使用内嵌 SVG，具备离线全屏、缩放、适应窗口、拖动和 Esc 退出能力。
- [ ] 个人 IP 标记仅保留单线双峰猫耳轮廓（一个主体路径），不绘制完整头部、五官、边框或装饰；16/20/24px 下清晰可辨。
- [ ] 功能图标主体几何元素不超过 2 个，统一单色与视觉重量，且语义仍可辨识。

## 自动化验收

- `tests/report.test.mjs`：验证 H1 层级、SVG 流程图、10 条分页、统一图标和侧栏切换状态。
- `tests/portal.test.mjs`：验证生成入口的折叠结构与图标栏样式。
- `tests/chrome-report-smoke.mjs`：在 375/768/1440px 验证卡片、多色图表、页码及流程图全屏/拖动/缩放/Esc。
- `tests/chrome-portal-smoke.mjs`：验证 iframe 门户折叠后仍显示纵向图标栏。
- `tests/report.test.mjs`：验证品牌标记单路径结构、功能图标几何元素数量，以及 16/20/24px 线宽缩放。

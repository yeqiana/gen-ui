# GEN-UI 专属图标 / GEN-UI Icons

这组原创 SVG 采用单色、少笔画和清晰轮廓。个人 IP 标记只保留“两峰一谷”的猫耳折线，不绘制完整头部、五官或附加装饰；功能图标以 1–2 个几何主体表达明确语义。

- `gen-ui-mark.svg`：单线双峰猫耳标记（个人 IP 核心符号）。
- `gen-ui-spark.svg`：灵感与生成。
- `gen-ui-table.svg`：表格与筛选。
- `gen-ui-chart.svg`：数据可视化。
- `gen-ui-tab.svg`：站内标签切换。
- `gen-ui-external.svg`：新标签页打开。
- `gen-ui-drawer.svg`：抽屉详情。
- `gen-ui-form.svg`：表单编辑。

品牌标记只允许一个主体路径，保持双峰猫耳轮廓；不绘制完整头像、五官、边框或装饰。功能图标尽量控制在 1–2 个几何主体，使用单色和一致的视觉重量，不可为了抽象而损失语义；品牌标记需在 16/20/24 px 下保持清晰。图标不可替代“新标签页”“站内标签”等文字提示；图标化按钮需提供中文 `aria-label` 和悬停/聚焦提示。Emoji 是少量语义锚点（通常每页 1–4 个），不与功能图标混用，也不能替代状态文字。所有图标只作装饰时设置 `alt=""`，链接/按钮本身必须有清晰的可见中文文本。

多页面门户另外提供四种纯 CSS 语义小图标（概览、记录、状态、交付），不额外加载远程图标。收起后仅展示一列图标，展开按钮始终留在侧栏内；每个图标都配有中文 aria-label 与 title。

该目录包含可编辑的矢量资产，不依赖远程 CDN。

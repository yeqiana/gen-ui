# GEN-UI 专属图标 / GEN-UI Icons

这组图标采用统一的紫蓝描边、珊瑚色强调与“灵感猫”标识。均为项目内原创 SVG，可直接在页眉、侧边栏、工具栏、站内标签提示或页脚引用。

- `gen-ui-mark.svg`：品牌主标识（猫耳 + 灵感星）。
- `gen-ui-spark.svg`：灵感与生成。
- `gen-ui-table.svg`：表格与筛选。
- `gen-ui-chart.svg`：数据可视化。
- `gen-ui-tab.svg`：站内标签切换。
- `gen-ui-external.svg`：新标签页打开。
- `gen-ui-drawer.svg`：抽屉详情。
- `gen-ui-form.svg`：表单编辑。

在业务正文中不要反复堆叠品牌图标；图标不可替代“新标签页”“站内标签”等文字提示。所有图标只作装饰时设置 `alt=""`，链接/按钮本身必须有清晰的可见中文文本。

该目录包含可编辑的矢量资产，不依赖远程 CDN。

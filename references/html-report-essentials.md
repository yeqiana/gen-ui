# GEN-UI · 静态 HTML 报告要点（按需）

> **适用边界：** 用户明确要求离线 HTML/网页报告，且主要是静态章节、表格和结论时才加载。普通问答和未指定格式的“报告”仍用 Markdown；复杂交互、真正独立的单文件、专业语义图或多页门户转用 [完整 HTML 合约](html-report-contract.md)，不得删减已要求的能力。

## 一、先保证内容

1. **事实优先：** 结论在前，后接依据、限制、风险和待办；用户提供的数量、版本、条件保持准确。设计建议用「建议/待明确」，未实际验证用「待验证」，不得把它们写成已上线或已通过。
2. **章节清晰：** `html lang="zh-CN"`，一个 H1；H2/H3 组织目录，H4 为正文。中文标题统一采用「一、二……」「（一）（二）……」，不得与小数层级混排。
3. **按需表达：** 方案比较用表格，步骤用有序列表；仅在真实数据、关系与读者问题需要时引入图表。不编造调用关系或阶段门槛；静态报告不添加无功能的筛选器、复制按钮、弹窗或仪表盘。

## 二、离线与阅读要求

- **真实左侧导航：** 保留可见的 `<aside class="doc-toc">`、`<nav>`、`<ul class="toc-list">` 和指向 `<main>` 内真实 ID 的锚点。即使 JavaScript 失效，也必须能点击静态目录。按现有项目契约引入**本地** `heading-nav.js`，不要凭空引用不存在的资源。
- **结构不能自由改写：** 静态技术文档必须用同一个 `<div class="doc-layout">` 同时包住 `<aside class="doc-toc">` 与 `<main class="doc-main genui-typography">`。`heading-nav.js` 实际只为 `main.doc-main` 和位于 `.doc-layout` 中的 `.doc-toc` 初始化折叠控件，缺任一层都会让折叠失效；不要用自制的 fixed 侧栏替代此结构。侧栏内保留 `<p class="toc-brand">` 和上述静态目录；`main` 顶部提供 `<details class="mobile-toc">` 及同一批有效锚点，让 375px 能开合目录。引用仓库现有的 `demo/documents/assets/document.css`、`assets/heading-nav.css`、`assets/heading-nav.js`、`assets/typography.css`（输出时按实际路径计算相对引用），不要只引用 JS 却忽略布局 CSS。
- **样式：** 背景 `#FFFFFF`、正文 `#1A1C1F`、强调 `#3A83F7`，正文 14px、代码 12px、系统字体。移动端不出现整页横向溢出；宽表格单独可横向滚动。
- **阅读排版：** 按需应用 [轻量 Typography 规则](typography.md)，正文标记 `genui-prose`，中文正文在正常章节内自然占满宽度、超宽阅读列最多 62ic，英文默认 72ch，并保持行高 Token；不要对中文正文使用 `text-wrap:balance` 提前换行；导航折叠后主体内容居中、正文行宽有限，宽表格、代码和 SVG 不受限。单文件 HTML 将小型 CSS 内联。
- **资源：** CSS/JS/SVG 使用本地相对路径并核对资源存在；不依赖 CDN、远程字体或在线图片。引用外部公开资料时，放在文末参考资料中，不将其当作运行依赖。
- **交互与可访问性：** 链接、导航和必要的折叠控件可用键盘访问；有图标按钮时必须有可读名称。无需交互的报告就不要制造可点击假按钮。
- **图片与导航：** 真实内容图片及图片链接只能在**当前页面**打开带遮罩的查看层，不能跳转到裸图片 URL；复用本地 `assets/media-viewer.css/js`，支持滚轮缩放、拖动、Esc 关闭以及独立全屏。导航、品牌、装饰图标不是内容图片，不自动放大。左侧导航只有目录 `nav` 自身纵向滚动，目录树与侧栏容器不能叠加滚动；展开状态下折叠按钮不带边框；折叠后隐藏单独的展开按钮（不占位），品牌区默认只展示原版 M 形 SVG，鼠标悬停或键盘聚焦时替换为右箭头，单击 M 区域或按 Enter/Space 即展开导航；折叠后阅读区域保持居中。参考样式使用约 58px 的桌面折叠栏、居中的 M/箭头/18px 目录图标，以及约 4% 蓝色透明度的轻微悬停底色；不能只靠外层 `main` 居中来判断阅读区已居中。
- **元数据：** 报告生成时间据实记录到秒。可见 `<time>` 必须如 `2026-11-13 11:30:00`，不要在正文显示 `+08:00` 或 `Z`；机器可读 `datetime` 可带时区。使用仓库中实际存在的本地 GEN-UI SVG favicon，不伪造路径。

## 三、交付与边界

静态正文优先成形，再加入样式与导航；不为装饰增加章节、空数据或伪造进度。不使用不可信的模型生成代码直接操作外部系统，不向用户保证未执行的动作已经成功。

本模式面向**仓库内可引用本地资源**的静态页面；如果用户要求真正独立的单文件、自定义交互或复杂可视化，则切换完整合约，而不是把完整功能压缩成一个不可用的空壳。

正常交付先执行 `node scripts/validate-html-report.mjs <report.html>`；需要真实交互验收时，对可信本地 HTML 执行 `node scripts/accept-html-delivery.mjs <report.html> <evidence-dir> --require-image`（无内容图片时省略最后一项并注明图片交互未覆盖）。该脚本检查实际阅读区居中、导航和图片弹层并保存截图及 JSON；不可用 Demo 代替生成文件。**用户明确要求跳过测试时不执行**，交付说明如实标注「未测试」。
